# 検出と記録

## 処理の流れ

1. センサーのcm/s²をm/s²に変換し、約1秒の静止で重力とオフセットを求めます。
2. 重力を差し引いた加速度と入力ベクトルの大きさの変化から動作を検出します。
3. 動作中は重力ベクトルを固定し、3軸加速度を台形積分します。
4. 減速・静止・時間上限で区間を閉じ、速度ベクトルの最大値を記録します。
5. 腕を戻した後に重力の推定を更新し、静止と待機時間を満たすと再び準備完了になります。

開始時の静止補正、計測、戻り待ちを別の状態として管理します。動作区間は40〜650ms、前方向の加速が3サンプル以上必要で、推定速度が0.4m/s以上の区間だけ記録します。動作開始の加速度しきい値は低・標準・高で8・6・4m/s²です。単発の衝撃、過大入力、250msを超えるサンプル欠落を除外します。

振動通知中と直後の加速度は除外します。成功通知はローカル保存が成功した後に鳴らします。画面終了時にはセンサー、振動、タイマーを停止します。

## 精度の限界

表示するのは手首の推定ピーク速度です。拳の実速度、打撃力、反応時間ではありません。ジャイロによる姿勢補正や外部基準との較正は行っていません。手首の回転、装着の緩み、センサーのサンプリング頻度や飽和によって誤差が生じます。

ジャブとフック、歩行などの分類器はありません。計測はジャブだけを一発ずつ打つ練習を想定しています。

疑似波形では20・25・50・100Hzの短いジャブ、構えの角度変更、静止ノイズ、単発衝撃を確認しています。実機の検出率と速度精度は未検証です。1.1.0では検出条件と積分区間を変更しており、以前の版との速度比較には条件差があります。

## データ

時計のLocalStorageに直近30回、各200発まで保存します。一発の検出ごとに練習全体を保存し直します。上限に達すると古い練習から置き換わります。

履歴には開始・終了時刻、感度、検出ロジックのバージョン、各打の推定速度・検出時刻・区間の長さを記録します。単位切り替えは表示だけに適用します。保存に失敗した練習はメモリー上に保持し、再試行できるよう新しい計測を止めます。

スマートフォンやクラウドへの同期はありません。アンインストールすると履歴は消えます。
